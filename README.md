## AutoCalculator (통합 미세조직 및 자동화 분석 시스템)

현재 버전은 `version.txt`를 따릅니다. 프로그램 화면 하단과 Image Analyzer 헤더에도 같은 값이 표시됩니다.

재료 공학 연구 및 품질 분석을 위한 **범용 미세조직 자동 분석 툴**입니다. 본 프로그램은 EBSD 데이터 분석, XRD 분석, 그리고 이미지 기반 두께 자동 측정 등 다양한 기능을 하나의 대시보드에서 제공합니다.

### 🚀 통합 솔루션 개요

AutoCalculator는 단순한 데이터 계산기를 넘어, 실험 데이터(XRD, EBSD)와 이미지 데이터(Microstructure)를 결합하여 정량적 분석 결과를 도출하는 통합 시스템입니다.

### ✨ 핵심 모듈 및 기능

#### 1. XRD & 미세조직 분석 (Microstructure Module)
- **XRD 데이터 처리**: XRD 피크 데이터를 분석하여 결정립 크기(Grain size)를 자동 산출합니다.
- **상 분석 (Phase Analysis)**: TC(Texture Coefficient) 및 C/N Ratio(질화물/탄화물 비율) 등 재료 배향성을 계산합니다.
- **정량적 평가**: 재료의 물리적 특성을 수치화하여 그래프 및 리포트로 제공합니다.

#### 2. 코팅 두께 자동 측정 (Auto-Thickness Module)
- **에지 검출 알고리즘 (Edge Detection)**: 이미지 처리 알고리즘을 통해 다층 코팅(Multi-layer)의 경계를 자동으로 인식합니다.
- **자동 두께 산출**: 수동 측정의 오차를 줄이고, 이미지 내 여러 지점의 두께와 편차를 자동으로 계산합니다.
- **실시간 캔버스 분석**: 분석된 레이어를 캔버스 위에서 시각적으로 확인하고 수정할 수 있습니다.

#### 3. 고정밀 EBSD 분석 (EBSD Module)
- **결정립 분석**: EBSD(.ang) 파일의 결정립 크기를 면적 가중치 기반(D10, D50, D90)으로 정밀 산출합니다.
- **상 분율 측정**: 상(Phase) 간의 결합성 및 분율을 고해상도 이미지 파이프라인으로 분석합니다.
- **특수 경계 검출**: Sigma-2 등 Coincidence Site Lattice(CSL) 경계 특성을 정량화합니다.

### 🛠 기술적 특징

- **통합 대시보드**: React와 TypeScript 기반의 현대적인 UI로 모든 분석 모듈을 직관적으로 제어합니다.
- **고성능 연산 파이프라인**: Python(NumPy, SciPy) 기반의 강력한 분석 코어를 활용하여 대용량 데이터를 빠르게 처리합니다.
- **플렉서블 실행 환경**: 전용 런처(`START_HERE.bat`)를 통해 복잡한 환경 설정 없이 실행할 수 있는 포터블 환경을 제공합니다.

### 📦 시작하기 (설치 및 실행)

1. **배포용 파일 하나 받기**: [AutoCalculator.cmd](https://github.com/shin9602/Microstructure-Analyzer/releases/latest/download/AutoCalculator.cmd)를 다운로드하세요.
2. **더블 클릭해 실행**: `AutoCalculator.cmd` 옆에 `AutoCalculator` 폴더를 자동으로 만들고 그 안에 최신 프로그램을 설치합니다. 이후에도 같은 폴더에서 업데이트·실행합니다. 이미 설치된 프로그램 폴더 안에서 실행하면 그 설치를 그대로 사용합니다.
3. 첫 실행에 필요한 Node.js·Python 환경을 준비하고 프로그램을 시작합니다. 이후 같은 파일 또는 설치 폴더의 `START_HERE.bat`를 실행하면 GitHub 자동 업데이트와 파일 무결성 검사를 수행합니다.

업데이트는 파일별 SHA-256 검증 후 적용하며, 누락·변경된 프로그램 파일은 같은 버전에서도 복구합니다. 적용 실패 시 교체 전 파일을 복원합니다. 분석 데이터와 설치된 실행 환경은 배포 ZIP에 포함하지 않습니다.

### EBSD 에타 영역 선택 · Phase 직접 지정

- **에타 영역 선택 모드**를 켜고 파일별 **에타 영역 선택**을 누릅니다. 원본 IQ 맵에서 스마트 영역 선택·스마트 지우개·브러시·지우개를 사용하고, 민감도·브러시 크기를 조절한 뒤 **선택 영역 적용**을 누릅니다. 실행 취소와 다시 실행을 지원합니다.
- 스마트 선택은 클릭 지점과 IQ가 비슷한 연결 영역을 선택합니다. 사용자가 선택 결과를 확인해 에타 영역으로 지정합니다. IQ 범위 슬라이더로 에타를 지정하는 방식은 아직 포함하지 않습니다.
- 에타는 WC·Co·gamma 입도·입계·연결도 계산에서 제외합니다. Co 입력값은 wt%이며, 적용 기준은 기본적으로 에타·제외 영역을 뺀 나머지입니다. 전체 시료 기준도 선택할 수 있습니다. 결과 Area%는 에타·사용자 제외 영역을 포함한 전체 유효 면적 기준입니다.
- 에타 크기는 상하좌우로 연결된 선택 영역의 등가원직경입니다. 서로 붙은 영역은 한 덩어리로 계산하고 시야 외곽 영역도 포함합니다. 결정 방위 기반 입도와 구분합니다. 영역 맵·크기 분포·영역별 CSV와 격자별 선택 CSV를 개별 또는 ZIP으로 다운로드할 수 있습니다.
- **상 분류 방식 → Phase 직접 지정**에서는 파일에서 읽은 Phase 번호·이름·대칭을 보고 WC·Co·gamma·에타·분석 제외를 지정합니다. 이 모드는 지정된 상을 IQ로 재분류하지 않으며 Co wt% 입력을 적용하지 않습니다. WC에는 육방정 대칭의 Phase가 필요합니다.

### 이미 분석한 데이터 불러오기

- 분석에 성공한 결과는 이 PC의 `%LOCALAPPDATA%/AutoCalculator/ebsd`에 저장합니다. 프로그램을 재시작해도 유지하며, OneDrive나 다른 PC로 자동 동기화하지 않습니다.
- **같은 데이터·조건이면 저장 결과 사용**을 켜면 원본 내용의 SHA-256, Co 함량, 상 분류·직접 지정, 에타 마스크, 분석 코드 및 주요 라이브러리 버전이 같은 결과를 재사용합니다. 파일 이름만 같거나 단순히 비슷한 데이터는 같은 결과로 취급하지 않습니다. 이름을 바꿔도 내용·조건이 같으면 개별 결과를 재사용할 수 있습니다.
- **저장된 분석 불러오기**에서 최근 20개 결과 모음을 파일 재업로드 없이 열 수 있습니다. 현재 분석 코드와 호환되며 관련 이미지·CSV·보고서가 남아 있는 기록만 표시합니다.
- 저장 결과 안내가 표시되며, 체크를 끄면 강제로 새로 계산합니다. 실패·불완전한 분석은 재사용하지 않고, 결과 파일이 삭제·누락되면 다시 분석합니다.
- 기존 버전에서 저장 기능 없이 생성한 결과는 자동으로 같은 조건임을 입증할 수 없어 새 캐시로 간주하지 않습니다. 업데이트 후 한 번 분석하면 이후부터 재사용할 수 있습니다.

### 다른 PC와 OneDrive에서 실행

- 지원 환경은 64비트 Windows입니다. 첫 설치·복구에는 인터넷 연결과 설치 폴더·사용자 임시 폴더의 쓰기 권한이 필요합니다.
- Python·Node.js를 미리 설치할 필요는 없습니다. 호환되는 기존 환경이 있으면 검사 후 사용하고, 없거나 버전·패키지가 맞지 않으면 전용 환경을 자동으로 준비합니다. 시스템에 설치된 Python 패키지는 변경하지 않습니다.
- Python은 64비트 3.10–3.12와 고정된 requirements 버전 및 실제 분석 모듈 import를 검사합니다. 전용 설치에는 Python 3.11.9를 사용합니다. Node.js는 18 이상 및 npm 실행을 검사하고, 필요하면 전용 Node.js를 설치합니다.
- PC별 전용 Python·Node.js와 캐시는 `%LOCALAPPDATA%/AutoCalculator/runtimes`에 분리합니다. OneDrive로 다른 PC의 실행 환경을 동기화해 재사용하지 않습니다. 분석용 업로드·결과도 로컬 임시 폴더에서 처리합니다.
- 실행기는 한글·공백이 있는 설치 경로를 인수로 전달하고 UTF-8로 Python을 실행합니다. 배포 ZIP은 OneDrive 원본을 임시 폴더로 실복사하고 파일별 해시를 검사한 후 만듭니다.
- npm 패키지 누락·버전 불일치·esbuild 실행 실패는 다시 설치합니다. 전용 런타임 복구 시 기존 폴더는 `.repair_...` 이름으로 보존합니다.
- 회사 네트워크·백신 정책이 다운로드나 실행을 차단하는 환경, 읽기 전용 폴더, 32비트 Windows까지 무조건 실행되는 것은 아닙니다. 실패 원인은 `launcher.log`에 기록합니다.
